# 04 — UI

## Tema

Dark AMOLED `#000000` bg, `#10141F` cards, `#1B2133` seleção, `#232B40` bordas, texto `#F5F7FA`, muted `#8A91A6`.
Primárias frias: magenta `#D946EF`, violeta `#6D28FF`, azul `#2F80FF→#2EC5FF`, teal `#3EDDD0`.
Status: pago `#22C55E`, a vencer `#FACC15`, atrasada `#EF4444`, crítico `#FB923C`.
Ícones Lucide / `expo-vector-icons` por categoria + status. Sem emoji final.

## Destaque

`PurchaseCard + InstallmentTimeline`: card (loja + data, total, valor parcela, `x/y pagas`, progresso, badge tipo) + tap expande accordion 200–250ms ease-out com timeline `mes - valor - pago sim/não`.

## Telas

- Member: Home (minha fatura), Meus lançamentos (lista + timeline), Histórico.
- Admin extra: Visão geral família, Detalhe por pessoa, Cobrança/pagamentos, Importar, Fechamento.
- Busca/filtros: loja, categoria, status, dono (admin), valor. Chips mês/ano horizontais.

## Regras RN (vercel-react-native-skills)

Listas virtualizadas (LegendList/FlashList), `Pressable`, strings sempre em `<Text>`, Reanimated transform/opacity, `Intl` hoisted, native stack/tabs, `expo-image`.
